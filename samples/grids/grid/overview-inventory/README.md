This folder contains a React application with the Grid Overview Inventory example.

- [Run in the samples browser](https://www.infragistics.com/react-demos/grids/grid/overview-inventory)
- [Source](./src/index.tsx)

## Run locally

```
git clone https://github.com/IgniteUI/igniteui-react-examples.git
cd igniteui-react-examples/samples/grids/grid/overview-inventory
npm install
npm start
```

Then open http://localhost:4200/ in your browser.
