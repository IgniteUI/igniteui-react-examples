This folder contains a React application with the Combo Remote Binding example.

- [Run in the samples browser](https://www.infragistics.com/react-demos/inputs/combo/remote-binding)
- [Source](./src/index.tsx)

## Run locally

```
git clone https://github.com/IgniteUI/igniteui-react-examples.git
cd igniteui-react-examples/samples/inputs/combo/remote-binding
npm install
npm start
```

Then open http://localhost:4200/ in your browser.
