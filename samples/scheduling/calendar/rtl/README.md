This folder contains a React application with the Calendar RTL example.

- [Run in the samples browser](https://www.infragistics.com/react-demos/scheduling/calendar/rtl)
- [Source](./src/index.tsx)

## Run locally

```
git clone https://github.com/IgniteUI/igniteui-react-examples.git
cd igniteui-react-examples/samples/scheduling/calendar/rtl
npm install
npm start
```

Then open http://localhost:4200/ in your browser.
